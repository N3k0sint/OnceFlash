OnceFlash

Easily send fully encrypted, secure notes or files with one click.

About

OnceFlash is a secure, open-source, zero-knowledge ephemeral note and file sharing service inspired by Cryptgeon and PrivNote.

how does it work?

Each note has a generated cryptographic key (256-bit AES) and a fresh 96-bit initialization vector (IV) generated directly in your browser via window.crypto.subtle (CSPRNG).

The note or file is encrypted with AES-256-GCM on the client side with the key before transmission. The server receives only opaque, unreadable ciphertext.

Data is stored ephemerally in volatile memory (RAM) and never persisted to disk. The server never sees the encryption key and cannot decrypt the contents of the notes even if it tried to.

how to use

  • 01
    Compose: Write your confidential note or drag & drop a file (up to 2 MB).
  • 02
    Configure Constraints: Select view limit (1 to 100 views, or burn on read) and expiration duration (5 minutes to 7 days).
  • 03
    Encrypt & Share: Click "Create Note" to encrypt client-side and copy your secret one-time link.
  • 04
    Decryption & Burn: The recipient opens the link; their browser decrypts the data in memory, and the secret is immediately purged from the server.
